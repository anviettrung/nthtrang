# NTH Trang — Film Photography

Site tĩnh, giao diện theo trang Pixieset gốc (nthtrang.mypixieset.com) và có thêm phần "Cuộn phim" ở trang chủ.

- Các trang: `/`, `/portfolio/`, `/weddings/`, `/elopements/` (Potrait), `/couples/`, `/about/`, `/contact/`
- `assets/style.css`: giao diện; `assets/app.js`: slider, menu, lightbox
- `assets/films.js`: dữ liệu phần Cuộn phim (tên phim, cảm xúc, danh sách ảnh)
- Các trang HTML được sinh bằng script `gen.py` (để ngoài repo)
